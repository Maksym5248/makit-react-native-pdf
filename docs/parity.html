Deliberately outside the renderer

The old source download fields (headers, method, cache, cacheFileName, expiration), trustAllCerts, remote URL/asset downloading, onLoadProgress, renderActivityIndicator and progressContainerStyle describe fetching and its UI. They are not exposed. The caller downloads/resolves an asset first, passes its local URI and owns its loading/error presentation. A local renderer reports completion/error; it cannot truthfully report network progress.

TableContent.mNativePtr is not portable or safe to expose across engines; IPdfOutline contains title, zero-based page index and children. Page and search indices otherwise start at 1. Search offsets/geometry are engine-local, not a cross-platform persistence format. No OCR, PDF editing, form persistence, annotation authoring or document synchronization is claimed.

Validation boundaries

The original implementation was exercised with React Native 0.83.1 New Architecture, React 19.2, iOS simulators and an Android arm64 emulator. The standalone and Expo examples use React Native 0.83.10. New build/runtime results must be recorded separately; previous simulator evidence does not verify this copy or Expo.

Build/codegen checks do not certify every OS, ABI, browser or React Native version. Peer ranges express the API baseline, not a tested compatibility matrix for all versions. Real-device release FPS, thermal behavior, screen-reader usability and absence of all memory leaks are not implied by simulator or mock tests.
